# RideShare Saver


## Project Overview

**RideShare Saver** is a student peer-to-peer carpooling platform tailored for Deakin University students. By connecting classmates who commute along similar routes to **Melbourne Burwood**, **Geelong Waurn Ponds**, and **Geelong Waterfront** campuses, RideShare Saver enables students to split fuel and parking costs, cut travel times, and travel safely together.
